# 💼 Abhinav Choudhary - Personal Portfolio Website

This is a personal portfolio website built using **Django, HTML, CSS, and JavaScript**. It showcases the skills, projects, and professional background of **Abhinav Choudhary**, a B.Tech graduate in Computer Science & Engineering and an Engineer Trainee.

---

## 🛠️ Tech Stack

- **Backend**: Django (Python)
- **Frontend**: HTML, CSS, JavaScript
- **Database**: SQLite (default with Django)
- **Other**: Bootstrap, Font Awesome

---

## 📌 Features

- 🧑‍💼 About Me section
- 🧠 Skills display
- 💡 Highlighted Projects
  - 🌿 Plant Disease Detector using CNN
  - 🌐 This Portfolio Website
- 📄 Downloadable Resume
- 📬 Contact Form (email support)
- 🔗 Social Media Links
- 📱 Responsive Design
